# NodeMCU-SDK
A simple RGB SDK for Daniel's SDK

## Snake Game

This repository now includes a simple terminal-based Snake game implemented in `snake.c`.

### Build

Compile the game using GCC:

```bash
gcc -Wall -Wextra -std=c11 snake.c -o snake
```

### Run

Execute the compiled program:

```bash
./snake
```

Use the `W`, `A`, `S`, and `D` keys followed by Enter to move the snake.
